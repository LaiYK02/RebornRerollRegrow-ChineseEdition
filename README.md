# 重生之我靠回城变强

**Reborn, Reroll, Regrow**

一款中文版网页卡牌桌游。骑士掷骰走过四片地貌，收集装备和道具，挑战七宗罪头目。率先击败第 100 格的「原初之王」即可获胜。支持单人试炼和最多四人的局域网对局。

## 开始游戏

本地运行需要 [Node.js 22 或更高版本](https://nodejs.org/)。下载或克隆本仓库后，Windows 用户可以双击 `start-game.cmd`。也可以在仓库目录运行以下命令，再打开[本机游戏菜单](http://127.0.0.1:3633/)。

```sh
node server.mjs
```

- **单人试炼**　设置骑士名字和颜色后，点击「单人试炼」。进度保存在当前浏览器。
- **创建房间**　房主从本机菜单点击「创建房间」，选中可用的局域网或 VPN 地址，复制给队友。等队友入座后，点击「开始游戏」。
- **加入房间**　队友直接打开房主分享的地址，或在网页菜单中输入该地址。断线后，请使用原浏览器和同一个房间地址重连。

联机期间请保持房主的服务窗口开启。查看[游戏规则](assets/rules.txt)和[联机指南](QUICKSTART.md)。

## GitHub Pages

仓库根目录可作为 GitHub Pages 的发布来源。在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，再选 `main` 和 `/(root)`。发布后，玩家可直接在网页中进行单人试炼。联机时由房主运行房间服务，玩家通过同一局域网或 VPN 连接。静态网页提供[房主工具包](assets/host-kit.zip)。

## 项目结构

| 路径 | 用途 |
| --- | --- |
| `index.html`、`app.mjs`、`styles.css` | 游戏菜单、房间界面和棋盘 |
| `game.mjs`、`battle.mjs`、`cards.mjs` | 回合结算、战斗和卡牌数据 |
| `server.mjs` | 局域网房间、聊天和重连 |
| `assets/` | 插画、游戏规则、界面模块和房主工具包 |

在仓库目录运行 `node --test` 可验证房间接口、游戏规则与界面输出。房间接口测试使用本机回环网络。
